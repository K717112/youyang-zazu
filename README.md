## 这是什么

《酉阳杂俎》是唐代段成式（约 803—863）所撰的笔记小说集，前集二十卷、续集十卷，共三十篇。内容包罗志怪传奇、朝野逸闻、方术医卜、异域物产、佛道灵验、草木虫鱼，被鲁迅称为「或录秘书，或叙异事，仙佛人鬼以至动植，弥不毕载」。

本仓库提供：

- **完整繁体原文**（1300 条，逐条编号）
- **完整简体白话译文**（19.1 万字，逐条对应）
- **原文/译文对照版**（便于对读、教学、引用核对）

其中续集卷一《支诺皋上》所载 **《叶限》**，是世界最早的「灰姑娘」型故事之一，比欧洲《格林童话》早约九百年。

## 样例

**卷一 · 003**

> **原文**：太宗虬鬚，嘗戲張弓掛矢。好用四羽大笴，長常箭一膚，射洞門闔。
>
> **译文**：唐太宗胡须卷曲（虬须，卷曲如龙的胡须），曾开玩笑地拉弓搭箭。他喜欢用四根羽毛的大笴（gǎn，长箭），箭身比普通箭长出一肤（四指宽为一肤，即长出四指），能射穿门扇。

## 翻译处理方式

原文保留**繁体**（存文献原貌，异体字如「賅」「貺」不改），译文一律**简体白话**。

- 人名、地名、国名、官名、物名照录，首见处加简注：`骨利幹國（北方游牧部族）`
- 难解词、通假字、名物就地括注：`大笴（gǎn，长箭）`、`一膚（四指宽）`、`禖祀（求子之祭）`
- 短小篇名条标为 `【篇名】忠志 —— <本篇内容提要>`，不硬凑成句
- 1300 条逐条对应，条号一一核对，无缺漏

## 校读提示

1. **底本是维基文库校录本**，不是宋刻影印。古籍传世异文多，《诺皋记》《支诺皋》几卷尤甚，个别条目有阙字、错简，译文按可读性直译，未替原文补字。
2. **译文是整理性白话**，不是学术译注。做论文引用、出版、教学时，诗句与名物解释仍应核对：
   - 中华书局 许逸民《酉阳杂俎校笺》
   - 中华书局 方南生 点校本
3. 译文由 AI 辅助生成并逐条校对，欢迎提 Issue 指正。
